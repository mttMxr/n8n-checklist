# 📚 Чек-лист курса n8n

Интерактивное веб-приложение для отслеживания прогресса изучения курса n8n с возможностью совместного использования.

## 🌐 Живая версия

**Приложение доступно по адресу:** https://maximilianus.github.io/n8n-checklist

## ✨ Особенности

- 🎯 **57 уроков** в 7 категориях
- 📊 **Интерактивная статистика** прогресса
- 🎨 **Современный UI** с анимациями
- 📱 **Адаптивный дизайн** для всех устройств
- 🔍 **Поиск и фильтрация** уроков
- 📝 **Заметки к урокам**
- 🎉 **Эффекты достижений** при 100% завершении
- 📤 **Экспорт/импорт** данных для командной работы

## 🤝 Совместное использование

### Для команды:
1. **Откройте приложение** по ссылке выше
2. **Отмечайте уроки** по мере прохождения
3. **Экспортируйте прогресс** кнопкой "Экспорт JSON"
4. **Отправьте файл** коллегам
5. **Импортируйте данные** от других участников

### Функции для командной работы:
- ✅ **Экспорт JSON** - сохраняет весь прогресс
- ✅ **Экспорт CSV** - для работы в Excel
- ✅ **Импорт данных** - загружает прогресс от других
- ✅ **Сброс прогресса** - для начала заново
- ✅ **Локальное сохранение** - данные не теряются

## 🚀 Быстрый старт

### 1. Установка зависимостей
```bash
npm install
```

### 2. Запуск в режиме разработки
```bash
npm start
```

Приложение будет доступно по адресу [http://localhost:3000](http://localhost:3000)

### 3. Сборка для продакшена
```bash
npm run build
```

## 🎨 Технологии

- **React 18** с TypeScript

- **Tailwind CSS** для стилизации
- **Lucide React** для иконок
- **LocalStorage** для сохранения данных

## 📊 Функциональность

### Отслеживание прогресса
- Автоматический подсчет завершенных уроков
- Процентное отображение прогресса
- Статистика по категориям
- Визуальные индикаторы

### Управление уроками
- Отметка выполненных уроков
- Добавление заметок
- Поиск по названию
- Фильтрация по категориям
- Скрытие/показ завершенных

### Экспорт данных
- Скачивание в формате JSON
- Скачивание в формате CSV
- Импорт данных от других участников
- Автоматическое сохранение в браузере

## 🎯 Категории уроков

1. **🚀 Основы и настройка** (6 уроков)
2. **🔗 Интеграции и подключения** (7 уроков)
3. **⚙️ Продвинутые настройки** (8 уроков)
4. **🤖 Создание AI-агентов** (11 уроков)
5. **📱 Социальные сети** (6 уроков)
6. **🎨 Контент и медиа** (10 уроков)
7. **🔧 Продвинутые техники** (9 уроков)
